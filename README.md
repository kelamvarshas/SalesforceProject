# WhatNext Vision Motors – Salesforce CRM Documentation

##  About the Documentation

This repository contains the complete documentation for **WhatNext Vision Motors**, a **Salesforce-based Automotive CRM Solution**.

The documentation explains the project requirements, Salesforce configuration, development, automation, testing, security, deployment, and the complete working flow of the CRM.

##  Project Working Flow

The documentation demonstrates the complete CRM workflow:

**Vehicle Creation → Dealer Creation → Customer Creation → Vehicle Order → Stock Validation → Stock Update → Automatic Dealer Assignment → Test Drive → Test Drive Reminder → Service Request → Pending Order Processing using Batch Apex**
